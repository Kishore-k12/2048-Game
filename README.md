\# 🎮 2048 Game



A Python-based implementation of the classic \*\*2048 puzzle game\*\*.



The objective of the game is to combine tiles with the same numbers to create higher-value tiles and eventually reach the \*\*2048 tile\*\*.



\## ✨ Features



\* 4×4 game board

\* Tile movement in four directions

\* Automatic tile generation

\* Tile merging logic

\* Score tracking

\* Game-over detection

\* Keyboard-based gameplay

\* Gameplay demonstration video



\## 🛠️ Technologies Used



\* \*\*Python\*\*

\* Python Lists and Data Structures

\* Functions

\* Conditional Statements

\* Loops

\* Game Logic

\## 🎮 How to Play



Use the keyboard arrow keys to move the tiles:



\* ⬆️ \*\*Up\*\* — Move tiles upward

\* ⬇️ \*\*Down\*\* — Move tiles downward

\* ⬅️ \*\*Left\*\* — Move tiles left

\* ➡️ \*\*Right\*\* — Move tiles right



When two tiles with the same number collide, they merge into one tile with their combined value.



\### 🎯 Goal



Reach the \*\*2048 tile\*\* and try to achieve the highest score possible!
